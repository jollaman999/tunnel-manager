# 업데이트 탭 - 새 릴리즈 확인과 자동 설치

작성: 2026-09-22 · 대상: tunnel-manager · 갈래: architectural

## 이 문서가 있는 이유

사용자가 부재중에 "업데이트 탭 하나 추가해서 구현하고 릴리즈·배포까지 알아서 해" 라고 위임했다.
승인 게이트를 대행했으므로, **무엇을 왜 그렇게 정했는지**를 남겨 돌아와서 뒤집을 수 있게 한다.

## 무엇을 만드나

화면에 `업데이트` 탭을 더한다. 그 탭이 하는 일은 셋이다.

1. 지금 버전과 최신 릴리즈를 나란히 보여주고, 새 것이 있는지 말한다.
2. 눌러서 지금 확인한다.
3. 자동 설치를 켜고 끈다. **기본은 꺼짐.**

## 자기 바이너리를 어떻게 바꾸나 - 가장 중요한 결정

### 안 하는 것: 프로세스가 자기 파일을 직접 덮기

`reexec_unix.go:37` 이 `os.Executable()` 로 다시 실행할 경로를 얻는다. Linux 에서 이 값은
`/proc/self/exe` 를 읽은 것인데, **바이너리를 rename 으로 덮으면 그 링크가 `<경로> (deleted)` 로
읽힌다.** 그 문자열로 `syscall.Exec` 을 부르면 실패한다.

즉 파일을 바꾼 뒤 기존 재기동 경로를 타면 **서비스가 내려간 채 안 올라온다.** 원격으로 복구할
수단이 없는 실패다. 그래서 이 방향은 버린다.

### 하는 것: `-install` 을 별도 프로세스로 띄우기

운영자가 손으로 하는 것과 **똑같은 경로**다.

```
exec.Command(<지금 바이너리>, "-install", "-db", <db 경로>)
```

`-install` 은 최신 릴리즈를 받아 `SHA256SUMS` 로 검증하고, 못 받으면 실행 중인 바이너리로
물러서고(`install/fetch.go:115` 의 주석), 파일을 놓은 뒤 서비스 매니저로 재기동한다.
`install.Install` 과 `install.Fetch` 는 이미 테스트가 두껍고, 오늘 v3.7.2·v3.7.3·v3.7.4
배포에서 세 번 실제로 탔다.

새로 짤 자기 교체 코드가 없다는 것이 이 선택의 전부다.

### 그래서 포기하는 것

- 이 프로세스는 자기가 언제 죽는지 모른다. 설치 프로세스가 서비스를 재기동하면서 죽인다.
  진행 상황을 화면에 끝까지 보여줄 수 없고, "설치를 시작했다" 까지만 말할 수 있다.
- 서비스로 등록되지 않은 채(손으로 띄운) 실행 중이면 `-install` 이 서비스를 등록해 버린다.
  그래서 **서비스로 등록돼 있지 않으면 자동 설치를 제공하지 않는다.**

## 설정

| 이름 | 기본값 | 무엇 |
|------|--------|------|
| `update_check_enabled` | `true` | 주기적으로 최신 릴리즈를 확인한다 |
| `update_check_interval_hours` | `24` | 확인 주기 |
| `update_auto_install` | **`false`** | 새 것이 있으면 자동으로 설치한다 |

**자동 설치가 기본 꺼짐인 이유**: root 로 도는 서비스가 말없이 자기 바이너리를 바꾸고 재기동하면,
그때 서 있던 터널이 전부 끊긴다. 언제 끊겨도 되는지는 이 프로그램이 알 수 없고 운영자가 안다.
확인은 켜 둔다 - 읽기뿐이고 GitHub 공개 API 한 번이다.

## 판정 규칙

버전 비교는 `semver` 세 자리 숫자로만 한다. `v` 접두사를 떼고 `.` 으로 갈라 숫자로 비교하며,
**숫자로 안 갈리면 "모름" 이지 "새 것 있음" 이 아니다.** 모르는데 새 것이 있다고 하면
자동 설치가 엉뚱한 것을 설치한다.

## 안 하는 것

- 특정 버전으로 내리거나 올리기. 최신 릴리즈 하나만 본다.
- 프리릴리즈. `releases/latest` 가 주는 것만 본다.
- 업데이트 전 백업. `-install` 이 하지 않는 일을 여기서 더하지 않는다.
- 설치 진행률. 위의 "포기하는 것" 참조.
- Windows 자동 설치. `reexec` 이 없는 플랫폼이라 서비스 매니저에만 기댄다 - 확인만 제공한다.

## 되돌리기 어려운 것

- 설정 표에 칼럼 셋이 붙는다. 되돌리면 칼럼은 남지만 읽는 곳이 없어 무해하다.
- 자동 설치가 켜진 채로 새 릴리즈가 나오면 그 노드는 스스로 재기동한다. 기본 꺼짐이 이것을 막는다.
